현재 작업 디렉터리 경로: !`pwd`

이 경로 아래의 디렉터리: !`ls -d */ 2>/dev/null`

프로젝트는 "지금 개발하는 앱"이다. 아래 순서로 정한다.

1. 경로가 앱 디렉터리 안이면(예: `.../app_development/running/app`) 작업 공간 바로 아래의
   앱 디렉터리 이름이 프로젝트다.
2. 경로가 여러 앱을 담은 작업 공간 자체이면(아래에 앱 디렉터리가 여럿 있다) 경로로는 알 수 없다.
   이 대화에서 가장 최근에 다룬 앱(파일을 읽거나 고치거나 빌드한 앱, 또는 사용자가 이야기한 앱)이
   프로젝트다. `hub/` 는 앱 개발 템플릿이라 그 자체를 작업한 경우에만 프로젝트로 본다.
3. 아직 어떤 앱도 다루지 않았으면 작업 공간 이름을 쓰고 "선택한 앱 없음"을 붙인다.

앱의 표시 이름(예: running → 톡톡런)을 알면 괄호로 붙인다.
한 줄만 간결하게 출력하고, 다른 설명이나 부연은 하지 않는다.

출력 형식:
현재 프로젝트: <앱 디렉터리 이름> (<표시 이름>)
