현재 작업 디렉터리 경로: !`pwd`

작업 공간의 프로젝트 디렉터리: !`ls -d /home/noble/app_development/*/ 2>/dev/null`

인자: `$ARGUMENTS`

위 디렉터리 하나하나가 프로젝트다(앱 하나 = 저장소 하나). `hub/` 는 앱 개발 템플릿이다.

## 인자가 있으면: 그 프로젝트로 바꾼다

1. 인자를 프로젝트에 맞춘다. 디렉터리 이름(대소문자 무시)이나 표시 이름(예: 톡톡런 → running,
   스도쿠 → sudoku)이 맞으면 그 프로젝트다. 앞부분만 맞는 후보가 하나뿐이면 그것으로 본다.
2. 맞는 프로젝트가 없거나 후보가 여럿이면 바꾸지 않는다. "`<인자>` 에 맞는 프로젝트가 없습니다"
   (후보가 여럿이면 후보 이름들) 한 줄을 쓰고, 아래 목록을 현재 표시 그대로 보여 준다.
3. 맞으면 Bash 로 `cd /home/noble/app_development/<프로젝트>` 를 실행한다. 이 대화의 이후 작업은
   이 프로젝트를 대상으로 한다(커밋·빌드·백로그는 이 디렉터리 기준).
4. "`<프로젝트>` 로 바꿨습니다" 한 줄 뒤에, 바꾼 프로젝트를 현재로 표시한 목록을 보여 준다.

## 인자가 없으면: 목록만 보여 준다

현재 프로젝트는 아래 순서로 정한다.

1. 이 대화에서 `/project <이름>` 으로 바꾼 적이 있으면 마지막으로 바꾼 프로젝트다.
2. 경로가 프로젝트 디렉터리 안이면(예: `.../app_development/running/app`) 그 프로젝트다.
3. 경로가 작업 공간 자체(`/home/noble/app_development`)이면 이 대화에서 가장 최근에 다룬
   프로젝트다(파일을 읽거나 고치거나 빌드한 앱, 또는 사용자가 이야기한 앱).
   `hub/` 는 템플릿 자체를 작업한 경우에만 현재 프로젝트로 본다.
4. 아직 어떤 프로젝트도 다루지 않았으면 현재 표시를 하지 않고, 목록 아래에
   "현재 선택한 프로젝트 없음" 한 줄을 붙인다.

## 목록 형식

표시 이름(예: running → 톡톡런)은 메모리나 대화에서 아는 것만 쓰고, 모르면 비워 둔다.
디렉터리 이름 순으로 정렬하고 열을 맞춘 코드 블록 하나로 쓴다. 현재 프로젝트 줄은 맨 앞에 `*`,
끝에 `<- 현재` 를 붙인다. 위에서 정한 한 줄 외에 다른 설명이나 부연은 하지 않는다.

```
프로젝트 목록 (/home/noble/app_development)
  hub       앱 개발 템플릿
  nqueens   N-Queens
* running   톡톡런          <- 현재
  sudoku    스도쿠 클래스
```
