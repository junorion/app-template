현재 작업 디렉터리 경로: !`pwd`

작업 공간의 프로젝트 디렉터리: !`ls -d /home/noble/app_development/*/ 2>/dev/null`

위 디렉터리 하나하나가 프로젝트다(앱 하나 = 저장소 하나). `hub/` 는 앱 개발 템플릿이다.

현재 프로젝트는 아래 순서로 정한다.

1. 경로가 프로젝트 디렉터리 안이면(예: `.../app_development/running/app`) 그 프로젝트다.
2. 경로가 작업 공간 자체(`/home/noble/app_development`)이면 이 대화에서 가장 최근에 다룬
   프로젝트다(파일을 읽거나 고치거나 빌드한 앱, 또는 사용자가 이야기한 앱).
   `hub/` 는 템플릿 자체를 작업한 경우에만 현재 프로젝트로 본다.
3. 아직 어떤 프로젝트도 다루지 않았으면 현재 표시를 하지 않고, 목록 아래에
   "현재 선택한 프로젝트 없음" 한 줄을 붙인다.

표시 이름(예: running → 톡톡런)은 메모리나 대화에서 아는 것만 쓰고, 모르면 비워 둔다.

출력은 아래 형식의 코드 블록 하나뿐이다. 디렉터리 이름 순으로 정렬하고 열을 맞춘다.
현재 프로젝트 줄은 맨 앞에 `*`, 끝에 `<- 현재` 를 붙인다. 다른 설명이나 부연은 하지 않는다.

```
프로젝트 목록 (/home/noble/app_development)
  hub       앱 개발 템플릿
  nqueens   N-Queens
* running   톡톡런          <- 현재
  sudoku    스도쿠 클래스
```
